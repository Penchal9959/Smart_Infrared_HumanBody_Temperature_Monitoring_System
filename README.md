# Infrared Body Temperature Screening

> **Archived.** The reviewed and corrected version of this project lives in
> [embedded-iot-projects / ir-temperature-screening](https://github.com/Penchal9959/embedded-iot-projects/tree/main/ir-temperature-screening), alongside the others from the same series. Work happens there;
> nothing here changes.

## What this was

Contactless fever screening for a shop or cinema entrance, built during COVID.
An MLX90614 reads forehead temperature without contact; an IR pair on the door
counts people in and out so occupancy can be capped.

## Hardware

Arduino UNO, MLX90614 infrared thermometer, IR sensor pair, 16x2 LCD, buzzer.

## Why it was archived

Twelve one-off repositories of two files each is not a portfolio, it is a
list. They were consolidated into one maintained repository with the
documentation and the build check they never had. This one is kept so
existing links still resolve.
