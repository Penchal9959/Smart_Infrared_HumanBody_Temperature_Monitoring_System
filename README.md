# Infrared Body Temperature Screening

A reviewed and corrected version of this project, with a build check and
fuller documentation, is in [embedded-iot-projects / ir-temperature-screening](https://github.com/Penchal9959/embedded-iot-projects/tree/main/ir-temperature-screening) alongside the others from the same
series.

## What this was

Contactless fever screening for a shop or cinema entrance, built during COVID.
An MLX90614 reads forehead temperature without contact; an IR pair on the door
counts people in and out so occupancy can be capped.

## Hardware

Arduino UNO, MLX90614 infrared thermometer, IR sensor pair, 16x2 LCD, buzzer.
